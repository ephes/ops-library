# Opaq offline company viewer

See the [operator contract](../../docs/source/howto/opaq_offline_viewer.md).
This directory prepares a synthetic hash-pinned HTML-only hosting bundle. It
installs nothing, registers nothing, reads no database and ships no credentials.
The example hostname remains proposed; choose an explicit offline port before
rendering. No real snapshot variant is supported.

The three regression HTML fixtures are unchanged public fictional artifacts from
Daybook integrated candidate `bd4e58bae6b9dce2c5c6941450e04c4086a6bfc3`.
Source SHA256 values and accepted filenames are pinned in `package.py`.
